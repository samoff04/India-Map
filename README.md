# India Map

A compact Java program that generates an ASCII-art representation of the **map of India** using encoded character data and decoding logic.

## Features

- Encoded ASCII-art generation
- Character and ASCII manipulation
- Bitwise operations
- Console-based execution
- No external dependencies

## Tech Stack

- Java
- ASCII / Character Encoding
- Loops
- Bitwise Operations
